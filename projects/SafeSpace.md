# SafeSpace

A full-stack AI-powered journaling and wellness web application that combines mood tracking, personal goal setting, and LLM-driven emotional insights in a single cohesive platform.

---

# Elevator Pitch

SafeSpace is a personal wellness platform built for people who want to take their mental health seriously without the clinical sterility of traditional therapy apps. It gives users a private, beautiful space to write daily journal entries, track their emotional patterns over time, set intentions, and receive feedback from an AI companion named Dr. Luna — all in one place.

The problem most wellness apps fail at is depth. They either offer a basic mood log with no meaning attached, or they bury useful analytics behind a paywall or a confusing interface. SafeSpace bridges that gap by combining structured journaling with real-time AI analysis, so every entry a user submits comes back with sentiment scores, keyword extraction, mood detection, and personalized encouragement — instantly.

What makes SafeSpace different is the combination of product surfaces in one cohesive experience: a personal dashboard with charts and a GitHub-style activity heatmap, a 20-slot affirmations board, a goal manifestation tracker, a community hub for sharing stories, and an AI insights engine that synthesizes writing patterns across weeks and months. These aren't isolated features — they feed into a single user profile with points, levels, and streaks that reward consistency.

The technical foundation is a production-grade MERN stack with JWT authentication, rate limiting, helmet security headers, multi-key API rotation for the Groq LLM backend, and a modular Express REST API — the kind of engineering that reflects real-world production thinking, not just a weekend prototype.

---

# Product Overview

SafeSpace is built for individuals who journal regularly or want to start. The target user is someone interested in self-improvement, emotional wellness, or personal growth who wants more than a blank text box — they want their journal to talk back.

The primary workflow starts at sign-up. A user creates an account, lands on a personal dashboard scoped to their username (e.g., `/sarah`), and begins writing daily entries. Each entry captures a title, free-form content, a primary mood with intensity, optional tags, and privacy settings. On submission, the backend immediately sends the content to an LLM for analysis and returns sentiment scores, detected mood, extracted keywords and themes, actionable suggestions, and a points reward.

Over time, the dashboard surfaces this data as visual trends — line charts for 7-day and 6-month mood trajectories, a bar chart for mood distribution, a happiness trend chart, a GitHub-style activity heatmap covering the past year, and a calendar view with dots marking journal days. Users accumulate points and progress through six named levels ("Novice Journaler" → "Master of Mindfulness") with a progress bar showing distance to the next level.

Beyond journaling, users fill a 20-slot affirmations board with personal positive statements, create and track manifestations (goals) organized by category and priority, and participate in a community hub where they can share stories and tips with other users. An AI insights page analyzes writing patterns over configurable time windows, identifying the most active writing days and hours, top recurring themes and keywords, writing length distributions, and emotional arc summaries generated by the LLM.

# Problem Statement

Mental wellness is deeply personal, yet most journaling tools treat it like a note-taking app. Users write into a void with no feedback, no patterns revealed, and no sense of progress. This makes it hard to stay consistent, and consistency is exactly what makes journaling effective.

The tools that do offer analytics are either too simplistic (just a mood emoji tracker) or too clinical (designed for therapists, not individuals). And the AI therapy tools that have emerged recently lack the structured self-reflection layer that makes journaling therapeutic in the first place.

SafeSpace solves this by making the journal entry itself the input to an AI analysis pipeline, returning immediate, personalized, emotionally intelligent feedback. It wraps that feedback in a gamification system that rewards consistency, and it adds supplementary features — affirmations, manifestations, community — that address the whole practice of wellness rather than just the writing habit.

# Key Features

## Authenticated Personal Space
Every user gets a private, username-scoped workspace. Routes are protected with JWT middleware and client-side route guards. Users can configure privacy settings at both the account and entry level. The authentication system handles registration, login, token-based session persistence (via localStorage), and logout with server-side token invalidation.

## AI-Powered Journal Analysis
When a journal entry is submitted, it is sent to the Groq LLM API (via a ChatbotService layer) for full analysis. The AI returns a structured JSON payload including sentiment classification, a float sentiment score (-1 to 1), detected primary and secondary moods, mood intensity, extracted keywords and themes, therapeutic suggestions, an encouragement message, and a points reward. This analysis is stored alongside the entry in MongoDB and informs all downstream analytics. If the AI's detected mood differs from the user's self-reported mood, the stored mood is corrected automatically.

## Personal Dashboard with Visual Analytics
The dashboard aggregates user stats and journal data into a rich visual interface. It includes six stat cards (total entries, points, streak, average points, most common mood, best day score), four charts (7-day mood trend, 6-month mood trend, happiness bar chart, mood distribution), a GitHub-style activity heatmap spanning 365 days, and a calendar with entry markers. A motivational quote is surfaced based on the user's level and streak.

## Dr. Luna AI Chat and Insights
Dr. Luna is an AI persona backed by the Groq API running Llama 3. She powers three distinct AI features: per-entry analysis (described above), a weekly narrative summary synthesizing the user's emotional journey across their last seven entries, and a comprehensive insights report that identifies emotional patterns, growth areas, strengths, and therapeutic observations across up to 30+ entries. The service includes API key rotation across up to three Groq keys for rate limit resilience, retry logic, and graceful fallbacks.

## Affirmations Board
A 20-slot grid where users write and store personal affirmations. Each slot is individually editable via an inline form with a textarea, save, cancel, and delete actions. The grid hydrates from the backend on load and persists changes via REST API calls with JWT auth headers. A rotating tips system guides users toward effective affirmation writing.

## Manifestations Tracker
A full CRUD goal-tracking feature where users log personal aspirations across seven categories (personal growth, career, relationships, health, financial, spiritual, travel) with low/medium/high priority flags. Goals can be marked as fulfilled, which timestamps the completion date. The UI shows fulfillment rate as a percentage and supports filtering by category and sorting by date, priority, or status.

## Insights and Writing Pattern Analytics
A dedicated insights API with four endpoints: comprehensive stats, mood analysis (with weekly mood grouping and intensity trends), writing patterns (by day of week, hour of day, word count buckets, reading time, tag usage), and progress tracking (monthly entry/word/points aggregates over six months, word count growth rate between recent and older entries). All of this feeds a frontend analytics view.

## Streak and Gamification System
User streaks are tracked at the model level with logic that handles same-day writes (no change), consecutive day writes (increment), and broken streaks (reset to 1). Points accumulate per entry based on AI scoring. A virtual `level` field (computed from points) and `progressToNextLevel` percentage are derived properties on the User model, keeping the display logic clean and consistent.

## Community Hub
A post-and-react community feed where users can share stories, tips, and experiences under categories (mental health, gratitude, writing, lifestyle). The feed supports likes, comments counts, sorting (latest, popular, most comments), and category filtering. Users can submit new posts with a title, content, and category.

# Engineering Highlights

The backend is an Express.js REST API with eight route modules: auth, user, journal, community, chatbot, insights, manifestation, and affirmation. Security is handled with Helmet for HTTP headers, express-rate-limit (100 requests per 15 minutes), bcryptjs with a cost factor of 12 for password hashing, and JWT for stateless authentication via a `protect` middleware.

MongoDB with Mongoose powers the data layer. The User model includes virtual properties (`level`, `progressToNextLevel`) that are computed from raw point totals, keeping derived state out of the database while making it available in JSON responses via `toJSON: { virtuals: true }`. The journal route includes input validation via `express-validator` with field-level constraints.

The ChatbotService is a resilient LLM integration layer. It manages up to three Groq API keys with round-robin rotation and per-request fallback logic — if one key hits a 401 or 429, it automatically retries with the next key. It supports both JSON-mode and plain-text LLM requests, handles markdown-wrapped JSON from model responses, and provides hardcoded fallback responses so the app remains functional when the LLM is unavailable.

The frontend is a React SPA using React Router v6 with username-parameterized protected routes (`/:username`, `/:username/journals`, etc.). Charts are rendered with Recharts (line and bar charts) and Chart.js (pie/arc). The activity heatmap is a custom-built component that generates 365 days of cells aligned to correct day-of-week columns with month labels, matching the GitHub contribution graph pattern. `react-calendar` is used for the streak calendar.

Journal entries support pagination, full-text search (MongoDB `$regex` across title, content, and tags), and multi-field sorting (date, alphabetical, points). Entries have a same-day edit/delete restriction enforced on the backend via a `canEdit()` / `canDelete()` instance method. User stats (total entries, points, mood counts, streak) are updated transactionally with every journal entry creation, update, or deletion.

# AI / ML Components

SafeSpace's AI layer is built around prompt engineering on top of the Groq API (Llama 3 8B). Three distinct prompt templates handle different tasks:

Entry analysis uses a structured prompt that asks the model to act as a therapist analyzing a single journal entry, returning a strict JSON schema with sentiment, mood, keywords, themes, suggestions, encouragement, and point value. The user's writing streak and cumulative mood history are injected into the prompt as context.

Insights generation aggregates up to 10 recent entry summaries alongside the user's profile stats (streak, total entries, level, mood distribution) and asks the model to identify emotional patterns, growth areas, strengths, and therapeutic observations.

Weekly summaries prompt the model in plain-text mode (no JSON schema) to write a narrative summary of the user's emotional journey over the past seven entries, including mood arc, key themes, moments of growth, and an encouraging closing message.

The service defaults to `llama3-8b-8192` with `temperature: 0.7` and a 1500 token limit. JSON mode is enabled via Groq's `response_format: { type: "json_object" }` parameter. A custom `_parseJsonResponse` method handles cases where the model wraps valid JSON in markdown code blocks.

# Product Thinking

SafeSpace demonstrates several deliberate product decisions. The username-scoped routing (`/username/journals`) creates a sense of personal ownership — the app feels like your space, not a generic SaaS dashboard. This also sets up a natural path toward public profiles if the privacy model is ever opened up.

The AI analysis is triggered synchronously on entry submission rather than as a background job, which means users see their feedback immediately. This reduces the perceived distance between writing and insight, making the feedback loop tight and rewarding.

The points and levels system is a lightweight engagement mechanism that rewards consistency without being coercive. The streak system in particular is designed to be forgiving of same-day behavior while still resetting on skipped days — a deliberate design choice that balances motivation with realism.

The 20-slot affirmations grid is an interesting constraint. Rather than an infinite list, the fixed size makes the board feel curated and intentional — you have to choose what stays. This is a product decision that reduces cognitive load and creates a sense of completeness.

The multi-key LLM rotation is a product reliability decision as much as a technical one. Groq's free tier has rate limits that would break the experience under any real usage. By rotating keys, the developer ensured the AI features stay live without requiring a paid tier.

The insights endpoint's configurable `?days=` parameter lets the frontend offer different time window views (7 days, 30 days, 90 days) with the same API, avoiding the need for multiple specialized endpoints and keeping the data model flexible.
